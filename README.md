# Spotter Weather Routing

React + Django weather-aware truck routing assessment, using Bun/Bunx for frontend tooling.

The repository currently contains the assessment, design references, and implementation plan. App implementation has not started.

- [Implementation spec](docs/implementation-spec.md)
- [Provider feasibility and setup constraints](docs/provider-notes.md)
- [Assessment PDF](docs/fs-assessment-spotter.pdf)
- [Locked visual reference](docs/visual_design_locked.png)

Implement the spec as one focused assessment app. Prioritize correct ETA-based weather/risk calculations, an excellent map interface, and understandable code. Deployment and Loom recording are follow-up work.
